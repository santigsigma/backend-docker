Exposicion - Backend REST API con Docker

🦀 Que es Rust?

Rust es un lenguaje de programacion de sistemas creado por Mozilla en 2015. Compila a codigo maquina nativo, lo que lo hace tan rapido como C/C++ pero con garantias de seguridad de memoria verificadas en tiempo de compilacion.

🦀 Para que sirve Rust?

Se usa para servidores web de alto rendimiento, herramientas CLI, sistemas operativos, blockchain y cualquier aplicacion donde se necesite velocidad y seguridad. Lo usan Discord, Cloudflare, Amazon y Microsoft.

🦀 Conceptos clave de Rust

Ownership (Propiedad)
Cada valor en Rust tiene un unico dueño. Cuando el dueño sale del scope (bloque de codigo), el valor se libera automaticamente de la memoria. Si intentas usar un valor despues de que se movio a otro dueño, el compilador te frena.
Sin Garbage Collector
Rust no tiene recolector de basura como Java o Go. La memoria se libera automaticamente gracias al sistema de Ownership. Esto significa que no hay pausas impredecibles en la ejecucion y el rendimiento es constante y predecible.
Compilacion estricta
El compilador de Rust es muy estricto: si tu codigo compila, probablemente funciona. Detecta errores de memoria, tipos incorrectos, accesos concurrentes peligrosos y referencias invalidas ANTES de que el programa se ejecute.

⚡ Que es Actix Web?

Actix Web es un framework web para Rust. Es uno de los frameworks mas rapidos del mundo segun benchmarks internacionales (TechEmpower). Permite crear APIs REST de alto rendimiento con muy poco consumo de recursos (~20-50 MB de RAM).

⚡ Para que sirve Actix Web?

Sirve para crear APIs REST, microservicios, servidores WebSocket y cualquier backend HTTP donde la velocidad y la capacidad de manejar miles de conexiones simultaneas sean importantes. En nuestro proyecto lo usamos para exponer 4 endpoints que se conectan a MySQL.

⚡ Conceptos clave de Actix Web

Actor Model (Modelo de Actores)
Actix usa internamente el modelo de actores: unidades independientes que se comunican por mensajes. Cada actor maneja su propio estado sin compartir memoria con otros, lo que evita problemas de concurrencia.
async/await (Asincronia)
Las funciones que manejan peticiones HTTP son asincronicas. Esto significa que pueden atender miles de conexiones simultaneas sin bloquear hilos del sistema. Se basa en el runtime Tokio.
HttpResponse
Es lo que devuelve cada endpoint. HttpResponse::Ok().json(data) devuelve un codigo 200 con datos en JSON. HttpResponse::InternalServerError() devuelve un 500 cuando algo falla.
Middleware
Son funciones que se ejecutan antes o despues de cada peticion HTTP. En nuestro proyecto usamos el middleware Logger que registra automaticamente cada request con su metodo, ruta, codigo de respuesta y tiempo de ejecucion.

INICIAR

1
cd ~/backend-docker
Entrar a la carpeta del proyecto
2
docker network create app-network
Crear la red interna para los contenedores
3
docker run -d --name db-mysql --network app-network -e MYSQL_ROOT_PASSWORD=mysecurepassword -e MYSQL_DATABASE=dbapp -e MYSQL_USER=appuser -e MYSQL_PASSWORD=mysecurepassword -p 3307:3306 -v $(pwd)/scripts/init.sql:/docker-entrypoint-initdb.d/init.sql mysql:8.0
Levantar MySQL
4
docker build -t backend-rust ./rust-actix
Compilar la imagen del backend
5
sleep 15
Esperar a que MySQL este listo
6
docker run -d --name backend-rust --network app-network -e APP_HOST=0.0.0.0 -e APP_PORT=8080 -e DB_HOST=db-mysql -e DB_PORT=3306 -e DB_USER=appuser -e DB_PASSWORD=mysecurepassword -e DB_NAME=dbapp -e RUST_LOG=info -p 8080:8080 backend-rust
Levantar el backend

PROBAR

7
docker ps
Ver contenedores corriendo
8
curl http://localhost:8080/health
Verificar que la API corre
9
curl http://localhost:8080/db-status
Verificar conexion a MySQL
10
curl http://localhost:8080/items
Listar items
11
curl -X POST http://localhost:8080/items -H "Content-Type: application/json" -d '{"nombre":"Item creado en clase"}'
Crear un item nuevo
12
curl http://localhost:8080/items
Verificar que se creo

APAGAR

13
docker stop backend-rust db-mysql
Detener contenedores
14
docker rm backend-rust db-mysql
Eliminar contenedores
15
docker network rm app-network
Eliminar la red
